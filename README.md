# Hyper-Realistic Lamp

Интерактивная демонстрация лампы накаливания, сделанная на HTML, CSS и JavaScript. Потяните за шнур на экране, чтобы включить или выключить свет.

## Возможности

- Анимированное переключение лампы с кратким мерцанием и покачиванием.
- Световой ореол, конус света и анимированные частицы при включенной лампе.
- Звук щелчка, синтезируемый через Web Audio API.
- Короткая вибрация на устройствах и в браузерах, которые поддерживают `navigator.vibrate`.
- Масштабирование элементов под размер экрана и управление касанием или указателем.

## Запуск

Сборка и установка пакетов не требуются. Откройте `index.html` в современном браузере.

Для запуска через локальный HTTP-сервер из каталога проекта выполните:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000). Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Управление

Нажмите или коснитесь области шнура под лампой. Каждое нажатие переключает состояние света. Звук запускается после первого пользовательского взаимодействия, как того требуют браузеры.

## Технологии

- HTML5 для структуры страницы.
- CSS для визуального оформления, адаптивных размеров и анимаций.
- JavaScript для переключения состояния, генерации частиц, звука и вибрации.
- Web Audio API для звукового эффекта; сторонние библиотеки не используются.
